Paste the base URL for a jailbreak package repository. RepoShelf looks for its Packages index.

This repository requires a manually entered, provider-authorized device ID. RepoShelf will not generate one for it.

A random 40-character archive ID is generated once and stored in your OS keyring. It is not read from or tied to a physical phone.

Sends model, iOS version, architecture, Sileo client headers, and device ID only to this HTTPS source.

Credentials are kept in your desktop's secure keyring and sent only to this HTTPS repository host. Use only credentials and access granted by the provider.

ABOUT REPOSHELF

Your local library

RepoShelf runs a web interface on this device. Add a repository, select packages or use Get all, and the original package files will be saved under the app's data/downloads folder.

Automation checks repositories on the interval you choose and downloads packages that are new or have a different version. It runs only while the server is running.

Downloaded packages are third-party files. Review the source before installing anything on a device.
