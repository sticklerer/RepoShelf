ABOUT REPOSHELF

Your local library

RepoShelf runs a web interface on this device. Add a repository, select packages or use Get all, and the original package files will be saved under the app's data/downloads folder.

Automation checks repositories on the interval you choose and downloads packages that are new or have a different version. It runs only while the server is running.

Downloaded packages are third-party files. Review the source before installing anything on a device.
